# YES2HEALTH BEAUTY

A premium, fully responsive landing page for YES2HEALTH BEAUTY - a Nigerian wellness brand specializing in Quantum Energy-infused products.

## Overview

YES2HEALTH BEAUTY offers a range of wellness products including jewelry, LED light therapy devices, beauty sprays, and fuel saver cards. This landing page showcases the brand's premium products with an elegant, modern design.

## Features

- **Responsive Design** - Mobile-first approach, works seamlessly on all devices
- **Premium UI/UX** - Elegant gold and green color scheme with luxury aesthetics
- **Product Showcase** - Beautiful product cards with hover effects
- **Interactive Sliders** - Testimonials and benefits sections with auto-slide functionality
- **Contact Form** - Integrated with Formspree for email delivery
- **WhatsApp Integration** - Floating chat button for instant customer communication
- **Smooth Animations** - Scroll-triggered animations using Intersection Observer
- **Energy Effects** - Subtle particle animations in the hero section
- **Legal Pages** - Privacy Policy and Terms of Service pages included

## Tech Stack

- HTML5
- CSS3 (Custom properties, Flexbox, Grid, Animations)
- Vanilla JavaScript (ES6+)
- [Formspree](https://formspree.io/) for form handling
- Google Fonts (Poppins, Playfair Display)

## Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/yourusername/yes2health-beauty.git
   ```

2. **Open in browser**
   - Simply open `index.html` in your web browser
   - Or use a local server like Live Server (VS Code extension)

3. **Configure Formspree** (optional)
   - Create an account at [formspree.io](https://formspree.io)
   - Replace the form ID in `index.html` with your own

## Customization

### Colors
Edit CSS variables in `css/styles.css`:
```css
:root {
    --primary-green: #1a6b3c;
    --primary-gold: #d4a853;
    --dark-green: #0d4a29;
    /* ... more variables */
}
```

### Contact Information
Update contact details in `index.html`:
- Phone/WhatsApp number
- Store address
- Business hours
- Social media links
